# 角色切层说明（Krita / GIMP 免费流程）

## 原图
`character_ref.png` —— AI 生成的全身立绘，蓝裙黑发、白色蕾丝雪花纹。

## 目标
切成 Live2D Cubism 可导入的 PSD，图层结构如下（从底到顶）：

| 图层名 | 内容 | 切层要点 |
|--------|------|----------|
| `body` | 躯干 + 裙子主体 + 腿/鞋 | 保留完整身体，脖子以下。 |
| `arm_L` | 左臂（观众视角）| 单独切出，肩到指尖，方便做微摆/呼吸。 |
| `arm_R` | 右臂（观众视角）| 同上。 |
| `hair_back` | 后脑勺/长发后层 | 放在脸和身体后面，做飘动。 |
| `face` | 脸型/耳朵/脖子肤色 | 不要包含五官。 |
| `hair_front` | 刘海/前额发 | 放在脸前面，可随呼吸微动。 |
| `hair_side` | 两侧鬓发 | 可单独做轻微摆动。 |
| `eyebrow_L` | 左眉 | 单独图层，做表情/眨眼联动。 |
| `eyebrow_R` | 右眉 | 单独图层。 |
| `eye_L` | 左眼（睁开）| 包含眼白、瞳孔、高光。 |
| `eye_R` | 右眼（睁开）| 同上。 |
| `eye_close_L` | 左眼（闭合）| 一条线/弧线，眨眼时切换显示。 |
| `eye_close_R` | 右眼（闭合）| 同上。 |
| `nose` | 鼻子 | 可省略，但建议保留。 |
| `mouth` | 嘴（默认闭合）| 口型：再切 `mouth_A`（张口）、`mouth_I`、`mouth_U`、`mouth_E`、`mouth_O` 用于发音口型。 |
| `head_accessory` | 蓝色蝴蝶结发饰 | 单独一层，可微动。 |
| `dress_detail` | 裙子蕾丝/雪花纹装饰 | 可选，可随呼吸微动增加层次。 |

## Krita 操作步骤
1. 打开 Krita → 文件 → 打开 `character_ref.png`。
2. 图层面板右键 → `添加图层`，按上表建空图层。
3. 用 **选区工具 / 套索 / 橡皮擦** 从原图抠出对应部位，放到对应图层。
4. 每切完一层，把该图层下面用**肤色/背景色补全**（避免移动时穿帮）。
5. 文件 → 导出 → `character.psd`（Photoshop 格式，Live2D 兼容）。

## 关键注意事项
- **眼睛切层要留足眼白**：眨眼/表情变形时瞳孔会移动，眼白范围不能太小。
- **头发前/后层交界要在头顶/耳朵附近**：不能切在脸中间。
- **嘴巴建议切 5 个发音口型**：A/I/U/E/O，配合 P5 语音口型阶段直接驱动。
- **裙摆蕾丝可单独一层**：呼吸时轻微缩放，角色更生动。
- **导出前合并所有可见图层？不要**。Live2D 需要每个部位独立图层。

## 切完之后的动作参数建议（Cubism 里设）
- `breath`：身体 + 胸/裙上下微移（振幅 2-3px），头发前后层反向微摆。
- `blink`：eye_L/R 与 eye_close_L/R 可见性切换，随机间隔 2-5s。
- `hair_sway`：hair_back / hair_side 左右微摆 + 物理模拟。
- `talk`：根据音频驱动 mouth_A/I/U/E/O 切换。
- `idle`：手臂轻微上下/旋转，身体轻微左右。
